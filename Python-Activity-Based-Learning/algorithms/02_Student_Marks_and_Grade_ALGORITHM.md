# Algorithm — Student Marks and Grade

Beginner-friendly step-by-step algorithm matching the current `main.py` program.

1. Start.
2. Input marks for three subjects.
3. Calculate total = m1 + m2 + m3.
4. Calculate average = total / 3.
5. If average is at least 90, assign grade A.
6. Otherwise, if average is at least 75, assign grade B.
7. Otherwise, if average is at least 60, assign grade C.
8. Otherwise, if average is at least 40, assign grade D.
9. Otherwise, assign grade Fail.
10. Display total, average, and grade.
11. Stop.
