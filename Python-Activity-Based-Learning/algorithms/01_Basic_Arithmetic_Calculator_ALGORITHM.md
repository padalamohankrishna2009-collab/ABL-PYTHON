# Algorithm — Basic Arithmetic Calculator

Beginner-friendly step-by-step algorithm matching the current `main.py` program.

1. Start.
2. Input two numbers, a and b.
3. Calculate and display a + b, a - b, and a * b.
4. If b is not zero, calculate and display a / b and a % b.
5. Otherwise, display a warning that division and remainder are not possible.
6. Stop.
