# Algorithm — Number Classification

Beginner-friendly step-by-step algorithm matching the current `main.py` program.

1. Start.
2. Input an integer.
3. If the integer is greater than zero, display positive.
4. Else if it is less than zero, display negative.
5. Otherwise, display zero.
6. If the integer divided by 2 has remainder zero, display even.
7. Otherwise, display odd.
8. Stop.
