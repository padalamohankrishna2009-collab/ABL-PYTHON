# Algorithm — Set Operations

Beginner-friendly step-by-step algorithm matching the current `main.py` program.

1. Start.
2. Input space-separated integers for set A and set B.
3. Convert the inputs into sets of integers.
4. Display set A and set B.
5. Calculate and display the union, intersection, and difference A − B.
6. Input an integer to search for in set A.
7. If the number is in set A, display that it is present; otherwise, display that it is absent.
8. Stop.
