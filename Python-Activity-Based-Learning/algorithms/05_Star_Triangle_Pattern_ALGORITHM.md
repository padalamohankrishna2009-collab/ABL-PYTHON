# Algorithm — Star Triangle Pattern

Beginner-friendly step-by-step algorithm matching the current `main.py` program.

1. Start.
2. Input the number of rows.
3. If rows is less than or equal to zero, display a message asking for a positive number.
4. Otherwise, repeat i from 1 through rows.
5. On each repetition, display a line containing i stars.
6. Stop.
