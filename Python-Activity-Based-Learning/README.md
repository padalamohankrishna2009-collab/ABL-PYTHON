
## Syllabus coverage
- **Unit I:** Python syntax, variables, data types, input/output, type conversion, arithmetic operators, and expressions.
- **Unit II:** if/elif/else, loops, strings, string methods, formatting, membership, and pattern generation.
- **Unit III:** lists, list operations, tuples, tuple unpacking, sets, set operations, and membership testing.
